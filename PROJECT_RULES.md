# CanaryGuard Project Rules

- Read PROJECT_SPEC.md before writing code.
- Treat PROJECT_SPEC.md as the single source of truth.
- Work only inside the existing CanaryGuard folder.
- Never create another root folder.
- Keep TODO.md updated after every major task.
- Do not duplicate folders.
- Do not duplicate files.
- Do not duplicate functionality.
- Use clean architecture.
- Generate complete implementations where practical.
- Improve existing code instead of replacing it unnecessarily.
- Maintain consistency across the project.
- Follow Python best practices.
- Keep documentation synchronized with the code.
