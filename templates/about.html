About CanaryGuard EDR Platform

Intelligent Endpoint Ransomware Detection & File Integrity Monitoring System.

Core Capabilities

  • Behavioral Ransomware Detection: Identifies malicious activity using Shannon Entropy analysis and file access pattern bursts without relying on static signature updates.
  • Canary Decoy Files: Automatically deploys hidden decoy documents (`Confidential_Report.docx`, `Payroll.xlsx`, etc.) that act as early warning traps.
  • Automatic Quarantine Engine: Instantly suspends and terminates malicious processes and their child threads upon detection.
  • Real-Time Dashboard: Powered by Flask, Socket.IO, and SQLite with multi-channel rotating logging.

Target Academic & Professional Specification

Designed as an enterprise-grade Endpoint Detection & Response (EDR) solution suitable for demonstration, GitHub publication, and academic evaluation.
